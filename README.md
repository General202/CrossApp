# CrossApp
Наскрізний проєкт з крос-платформного програмування.
Предметна область: Замовлення, Сутності: (клієнт, товар, замовлення, рядок замовлення)
Призначення: Оформлення замовлень покупців, облік товарів та автоматичний підрахунок підсумкових сум замовлень.
# Запуск проєкту
dotnet build
dotnet run --project src/Cli
# Середовище розробки
.NET SDK 9.0, VS Code, Windows 11 x64
