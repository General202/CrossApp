# CrossApp
Наскрізний проєкт з крос-платформного програмування.
Предметна область: Замовлення, Сутності: (клієнт, товар, замовлення, рядок замовлення)
Призначення: Оформлення замовлень покупців, облік товарів та автоматичний підрахунок підсумкових сум замовлень.

# Структура рішення (Solution)
src/Core — бібліотека класів (Class Library), що містить доменну логіку, сервіси та збір метрик.
src/Cli — консольний застосунок (UI шар), який підключає `Core` і відповідає за форматування виводу.

# Self-Contained VS Framework-Dependent
Self-Contained (автономна): містить у собі весь runtime .NET. Застосунок працює на будь-якому ПК без попередньо встановленого .NET SDK/Runtime, але займає значно більше місця.

Framework-Dependent (залежна від фреймворку): містить лише код програми та її бізнес-логіку. Має мінімальний розмір, але вимагає наявності встановленого .NET Runtime 9 на цільовій машині.

# Таблиця публікацій (win-x64)
self-contained = ~74.35 MB

# Запуск проєкту
Збірка всієї solution:
dotnet build

Запуск консольного клієнта:
dotnet run --project src/Cli

Запуск з прапорцем JSON:
dotnet run --project src/Cli -- --json

# Середовище розробки
.NET SDK 9.0, VS Code, Windows 11 x64
